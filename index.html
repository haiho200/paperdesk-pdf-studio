About editing

Select / Move lets you edit and drag added text. Replace PDF text covers the original with a background patch and new text; font size and style are matched automatically, with substitutes when needed. Cover hides content visually; it is not secure redaction. Original text underneath remains in the file.

Added text and marks are flattened into an image layer on export. Scanned text is not converted to editable text.
